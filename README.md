# StoryWeaver
StoryWeaver is a Java-based application designed to help writers organize and manage multiple fictional universes. It provides a centralized way to manage characters, relationships, and chronological story events while maintaining consistency throughout different fictional worlds.

MVP Features:
- Create, view, rename and delete fictional universes.
- Add, edit, delete, and search charcter profiles.
- Establish and manage relationships between characters.
- Record important story events and organize them chronologically.
- Save and load information using JSON files.

Future Features:
- Episode and chapter management.
- Automatic character age calculations.
- Family tree visualization.
- Connections between different fictional universes.
- Continuity checking to identify potential story inconsistencies.

Technology Stack:
- Language: Java
- Libraries: Java Collections Framework, java.io, java.nio.file, java.time, Gson
- Data Storage: JSON files
- IDE: IntelliJ IDEA
- Version Control: Git and GitHub

Project Structure:
- src/ - Java source code
- data/ - Saved fictional universe data
- docs/ - Project planning documents and system diagrams

Project Documentation:
- Eisenhower Matrix: docs/EisenhowerMatrix.pdf
- System Diagram: docs/SystemDiagram.pdf

Development Plan:
The project will be developed through eight milestones, each building on the other. These milestones will cover initial setup, universe management, character management, relationship management, timeline functionality, data persistence, integration and testing, and final documentation.

Future Goals:
The long-term goal is to expand StoryWeaver into a more comprehensive fictional universe management tool while maintaining a simple and accessible design.
